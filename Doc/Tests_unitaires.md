# Les tests unitaires

## Pourquoi des tests

Les tests unitaires vérifient le bon fonctionnement d’une unité de code isolée (fonction, méthode, classe) en la testant indépendamment du reste du programme. Leur objectif est de détecter les erreurs dès le développement et de s’assurer que chaque composant se comporte comme prévu.

### Intérêts principaux

. Détection précoce des bugs : Identifier les erreurs dès l’écriture du code, avant l’intégration.
. Facilitation des modifications : Permettre de refactoriser ou d’ajouter des fonctionnalités sans crainte de régression.
. Documentation vivante : Servir d’exemple concret sur l’utilisation du code.
. Amélioration de la qualité : Encourager un code modulaire, testable et maintenable.
. Automatisation : Intégrables dans des pipelines CI/CD pour des validations rapides et répétables.
